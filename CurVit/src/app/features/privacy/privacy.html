Política de Privacidad y Términos de Uso

Última actualización: 2025

Uso del sitio web

Este sitio web puede ser visitado libremente sin necesidad de registro ni creación de cuentas. La simple navegación por el sitio no implica la recopilación directa de información personal por parte del responsable del sitio.

Información proporcionada voluntariamente

El usuario solo proporciona información personal cuando decide contactarse de forma voluntaria, por ejemplo, mediante un formulario de contacto o correo electrónico.

La información proporcionada puede incluir datos básicos como nombre o correo electrónico, y se utiliza únicamente para responder la comunicación realizada.

Información técnica del servidor

Este sitio web no utiliza cookies, herramientas de seguimiento ni sistemas de analítica. No obstante, el proveedor de alojamiento web puede generar automáticamente registros técnicos del servidor.

  • Dirección IP
  • Tipo de navegador o dispositivo
  • Fecha y hora de acceso
  • Solicitudes realizadas al servidor

Estos registros no son utilizados para identificar al usuario ni son tratados directamente por el responsable del sitio.

Uso de la información

  • Responder consultas o mensajes enviados por el usuario
  • Mantener una comunicación puntual y solicitada

En ningún caso la información será vendida, compartida con fines comerciales o utilizada con propósitos publicitarios.

Datos sensibles y ubicación

Este sitio web no solicita ni trata datos sensibles, ni información de ubicación precisa del usuario.

Acceso de terceros

  • Cuando exista una obligación legal
  • Para proteger derechos legales o la seguridad del sitio
  • Con proveedores de servicios técnicos estrictamente necesarios para el funcionamiento del sitio

Conservación de la información

Los datos proporcionados voluntariamente se conservarán únicamente durante el tiempo necesario para atender la consulta realizada.

Seguridad

Se aplican medidas razonables para proteger la información manejada. Aun así, ningún sistema en Internet es completamente seguro.

Cambios en esta política

Esta política puede ser modificada en cualquier momento. Las modificaciones serán publicadas en esta misma página.

Aceptación

El uso de este sitio web implica la aceptación de los términos aquí descritos.
